# Kashmir Beyond — Travel & Experiences

A cinematic, mobile-friendly Kashmir travel website **prototype** hosted as a static project.

## Project
- Public website (after GitHub Pages is enabled): https://sakibautomation.github.io/kashmir-beyond/
- Main page: `index.html` (self-contained CSS and JavaScript)
- Image and legal notices: `credits.html`

## Publish with GitHub Pages
1. In GitHub, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then **Save**.
4. Once GitHub reports a successful deployment, open the project website URL above. GitHub Pages can take a short period to publish.

## Prototype limitations
- Site includes sample destinations, itineraries and a local-only enquiry text builder.
- Enquiries are **not** sent or stored; there are **no** live bookings, payments or business contact integration.
- A `noindex, nofollow` meta directive keeps this preview out of ordinary search indexing until business details, brand rights and content are verified.
- Travel conditions, activities and accessibility can change by season.
- Photos load from Unsplash and fonts from Google; see `credits.html`.

## Before commercial launch
- Verify the proposed name **Kashmir Beyond** against existing brands/trademarks, and register a suitable domain only after clearance.
- Add verified operator details, contact methods, real package inclusions, prices, booking policies, customer support and legally compliant privacy disclosures.
- Replace illustrative itineraries with verified offerings; confirm availability, permits and seasonal restrictions.
- Review all photo licenses and image provenance. No customer reviews or booking claims are made by this prototype.
